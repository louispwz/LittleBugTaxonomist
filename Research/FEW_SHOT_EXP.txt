J’ai travaillé sur le fine-tuning d’un modèle Image-Text (BioClip) sans utiliser de prompts textuels.
 Plutôt que d’ajouter une couche de classification lourde dès le départ, j’ai d’abord exploré une approche de type Linear Probe sur les features; le modèle évolue et je backpropage donc directement dans le réseau. Comme le code originel s’appuie fortement sur du texte (des descriptions), an a dû trouver une solution pour mapper les embeddings image -> classes sans générer de textes comme intrants. Plutôt que d’utiliser une cross-entropy classique adaptée à des logits de classes (0/1/2, etc.), j’ai opté pour une solution pragmatique : ajouter temporairement une couche linéaire (classifier head) attachée à la sortie du modèle et entraîner ensemble le modèle + ce classificateur. À l’issue de l’entraînement, je supprime ce classificateur et conserve les améliorations du modèle, en m’orientant ensuite vers une approche de prototypes comme ancres (mobiles ou fixes) pour poursuivre l’amélioration.
